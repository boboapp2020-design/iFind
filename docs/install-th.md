# คู่มือติดตั้ง — แอปค้นหาค่าสี & คุณภาพน้ำตาล (Mitr Lao)

แอปมือถือ (เปิดผ่านลิงก์ ไม่ต้องลงแอป) ทำงานบน **Google Apps Script + Google Sheets**
ผู้ใช้ 2 บทบาทแยกด้วย PIN — **QC** บันทึก/แก้ไขค่าคุณภาพ · **คลังสินค้า** ค้นหา + จัดการสต๊อก

ไฟล์ในโฟลเดอร์นี้:
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | Backend + ระบบ PIN + อ่าน/เขียนข้อมูล + ตรวจ Spec |
| `Migrate.gs` | ย้ายข้อมูล COA 52 แผ่น → ตาราง DATA |
| `Index.html` | หน้าจอแอปบนมือถือ |

---

## ขั้นตอนติดตั้ง (ครั้งเดียว ~10 นาที)

### 1) เปิด Apps Script ผูกกับ Google Sheet
- เปิดชีต **“คลังสินค้า คาสี”** (ที่ให้ลิงก์ไว้)
- เมนู **Extensions → Apps Script**
- สร้างไฟล์ให้ครบ 3 ไฟล์ แล้ววางโค้ดจากโฟลเดอร์นี้:
  - `Code.gs` (มีอยู่แล้ว วางทับ)
  - `+ → Script` ตั้งชื่อ `Migrate` วาง `Migrate.gs`
  - `+ → HTML` ตั้งชื่อ `Index` วาง `Index.html`
- กด **Save** 💾

### 2) สร้างตารางฐานข้อมูล
- เลือกฟังก์ชัน **`setup`** ที่แถบบน แล้วกด **Run**
- ครั้งแรกจะขออนุญาต → **Review permissions → Allow**
- จะได้ 2 แท็บใหม่ในชีต: **DATA** และ **CONFIG**
- ในแท็บ **CONFIG** เปลี่ยน PIN ได้เลย (เริ่มต้น: `PIN_QC = 1111`, `PIN_WAREHOUSE = 2222`)

### 3) ย้ายข้อมูลเก่าเข้า (COA 52 แผ่น)
- ในชีต: **File → Import → Upload** ไฟล์ `Update ค่าสี 2526.xlsx`
- เลือก **Insert new sheet(s)** → Import → ได้ 52 แท็บ
- กลับไป Apps Script เลือกฟังก์ชัน **`migrate`** → **Run**
- เปิด **Executions** (เมนูซ้าย ⏱) ดูสรุป เช่น
  ```
  ย้ายข้อมูลเสร็จ: รวม 180 แถว
  ✓ 525: 5 แถว
  ✓ 526: 5 แถว
  — sign: ข้าม (ไม่พบหัวตาราง Color/Polarization)
  ```
  แผ่นที่ขึ้น “ข้าม” คือหน้าที่ไม่ใช่ตารางผล (เช่น sign, Check) หรือรูปแบบแปลก — แจ้งผมได้ เดี๋ยวปรับตัวจับให้
- เมื่อข้อมูลเข้า DATA ครบแล้ว จะ **ลบ 52 แท็บ COA ทิ้งได้** (เก็บแค่ DATA + CONFIG)

### 4) เผยแพร่เป็นแอป (Web App)
- Apps Script → **Deploy → New deployment**
- ⚙ เลือกชนิด **Web app**
  - Execute as: **Me**
  - Who has access: **Anyone** (หรือ *Anyone with Google account* ถ้าต้องการจำกัด)
- **Deploy** → คัดลอก **Web app URL**
- เปิด URL บนมือถือ → **Add to Home screen** เพื่อใช้เหมือนแอปจริง 📱

## การใช้งาน
- **QC** ใส่ PIN → เห็นปุ่ม “＋ บันทึกค่าใหม่” และแก้ไขค่าคุณภาพได้ (แอปเช็ค Spec ให้ขณะพิมพ์)
- **คลังสินค้า** ใส่ PIN → ค้นหาเลข Lot, ใช้ “ค้นหาค่าที่เหมาะสม” (สีไม่เกิน / Pol ไม่ต่ำกว่า), แก้ตำแหน่งเก็บ + จำนวนคงเหลือได้ แต่แก้ค่าคุณภาพไม่ได้

## แก้ Spec / PIN
แก้ที่แท็บ **CONFIG** ได้ทันที (COLOR_MAX, POL_MIN, MOIST_MAX, INVERT_MAX, MA_MIN, MA_MAX, PIN_QC, PIN_WAREHOUSE) — ไม่ต้องแก้โค้ด

## อัปเดตโค้ดภายหลัง
แก้ไฟล์ใน Apps Script แล้ว **Deploy → Manage deployments → Edit → Version: New → Deploy** (URL เดิมไม่เปลี่ยน)

---
> หมายเหตุ: ระบบ PIN นี้เหมาะกับงานภายใน (แยกสิทธิ์ QC/คลัง) การเขียนข้อมูลตรวจ PIN ที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง
> ถ้าต้องการความปลอดภัยระดับสูง (บันทึกว่าใครแก้อะไรด้วยบัญชี Google) แจ้งได้ เปลี่ยนเป็นล็อกอิน Google ได้
